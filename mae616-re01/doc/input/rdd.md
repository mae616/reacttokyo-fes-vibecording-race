# プロジェクト概要

## コンテキスト（AI用）
- 目的: X（旧Twitter）風のSNSプラットフォームをローカル環境で構築する
- 背景: React Tokyo Fes vibecording race 向けの開発課題
- 想定ユーザー像: ローカルで動作確認する開発者自身

## 一言まとめ
フォロー/アンフォロー＋文章投稿＋タイムラインを備えたX風SNSのローカル版

---

# ユースケース

## コンテキスト（AI用）
- シナリオ1: ユーザー一覧を閲覧し、気になるユーザーをフォローする
- シナリオ2: 文章を投稿し、タイムラインに即時反映される
- シナリオ3: フォロー中ユーザー＋自分の投稿がタイムラインに表示される
- シナリオ4: ユーザー名をクリックしてプロフィール画面に遷移する
- MVP範囲: 全シナリオがMVP

---

# 機能要件

## コンテキスト（AI用）

### 機能一覧（優先度順）

1. **ユーザー一覧表示**
   - 5人以上のユーザーが表示される
   - ユーザー名からプロフィール画面に遷移できる
   - seedデータで初期ユーザーを投入

2. **フォロー/アンフォロー**
   - トグル動作（フォロー中ならアンフォロー、未フォローならフォロー）
   - UIとDBが一致する
   - 自分自身（viewerId）にはフォローボタンを表示しない

3. **文章投稿**
   - テキストを入力して投稿できる
   - DB保存され即時表示される

4. **タイムライン**
   - フォロー中ユーザー＋viewer自身の投稿のみ表示
   - createdAt降順で表示
   - 空タイムライン状態も起こり得る（seedで調整）
   - ユーザー名からプロフィール画面に遷移できる

5. **プロフィール画面**
   - ユーザー情報の表示
   - そのユーザーの投稿一覧
   - フォロー数/フォロワー数をDBから正しく集計して表示

### DoD（完了条件）
- ユーザー一覧に5人以上表示される
- フォロー/アンフォローがトグル動作し、UIとDBが一致する
- 文章投稿がDB保存され即時表示される
- タイムラインにフォロー中＋viewerの投稿のみcreatedAt降順で表示される
- プロフィール画面にユーザー情報＋投稿一覧が表示される
- フォロー数/フォロワー数がDBから正しく集計される
- タイムライン/ユーザー一覧からユーザー名クリックでプロフィール画面に遷移できる

# 技術スタック

## コンテキスト（AI用）

### フロントエンド
- 言語/ランタイム: TypeScript / Node.js
- フレームワーク: React (latest) + Vite
- スタイリング: Tailwind CSS
- ルーティング: react-router-dom
- 状態管理: useState / useEffect のみ
- 静的解析: ESLint（TypeScript対応、recommended設定）
- コード整形: Prettier

### バックエンド
- 言語/ランタイム: TypeScript / Node.js
- フレームワーク: Express (latest)
- ORM: Prisma
- DB: SQLite

### 設計方針
- APIレスポンスをそのままstateに入れ、派生計算は極力バックエンド側に寄せる
- viewerIdはログインの代替。UIにユーザー切替を入れるならstate管理にする
- 自分自身（viewerId）にはフォローボタンを表示しない
